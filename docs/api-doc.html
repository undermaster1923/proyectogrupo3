GET

/api/tipocambio

Devuelve el tipo de cambio del día actual (GTQ/USD). Primero busca en base de datos; si no existe, lo consulta al Web Service de Banguat y lo guarda.

URL
GET https://proyectogrupo3-rmb9.onrender.com/api/tipocambio
Parámetros

Ninguno.

Respuesta exitosa 200 OK
{ "fecha": "2026-06-03", "valor": "7.75", "source": "Banguat WS" // o "Database" si vino de caché }
POST

/api/tipocambio

Devuelve el tipo de cambio de una fecha específica. Recibe la fecha en el body como JSON.

URL
POST https://proyectogrupo3-rmb9.onrender.com/api/tipocambio
Body (JSON)
CampoTipoFormatoRequerido
fechastringYYYYMMDDSí
{ "fecha": "20260529" }
Respuesta exitosa 200 OK
{ "fecha": "2026-05-29", "valor": "7.74", "source": "Database" }
La fecha en el body va sin guiones (YYYYMMDD). La respuesta la devuelve con guiones (YYYY-MM-DD).
GET

/api/historialcambio

Devuelve los últimos 10 registros de tipo de cambio almacenados en base de datos, ordenados del más reciente al más antiguo.

URL
GET https://proyectogrupo3-rmb9.onrender.com/api/historialcambio
Parámetros

Ninguno.

Respuesta exitosa 200 OK
{ "items": 10, "data": [ { "fecha": "2026-06-03", "tipocambio": "7.75" }, { "fecha": "2026-06-02", "tipocambio": "7.74" }, ... ] }
GET

/api/agregarcuenta/{cui}

Consulta la cuenta de ahorro asociada a un CUI. El CUI se pasa directamente en la URL.

URL
GET https://proyectogrupo3-rmb9.onrender.com/api/agregarcuenta/1234567890123
Parámetro de URL
ParámetroTipoDescripción
cuinuméricoCUI del titular (13 dígitos)
Respuesta exitosa 200 OK
{ "numero_cuenta": "0483920174", "cui": "1234567890123", "tipo_cuenta": "Ahorro", "fecha_creacion": "2026-06-03", "saldo": "100.00" }
Respuesta de error 404 Not Found
{ "error": "No se encontró una cuenta asociada al CUI 1234567890123." }
POST

/api/agregarcuenta/{cui}

Crea una nueva cuenta de ahorro para el CUI indicado. Genera un número de cuenta de 10 dígitos automáticamente. El saldo inicial es Q100.00. No acepta body.

URL
POST https://proyectogrupo3-rmb9.onrender.com/api/agregarcuenta/1234567890123
Parámetro de URL
ParámetroTipoDescripción
cuinuméricoCUI del titular (13 dígitos)
Body

No requiere body.

Respuesta exitosa 201 Created
{ "numero_cuenta": "0483920174", "cui": "1234567890123", "tipo_cuenta": "Ahorro", "fecha_creacion": "2026-06-03", "saldo": "100.00" }
Respuesta de error 409 Conflict
{ "error": "Ya existe una cuenta registrada para el CUI 1234567890123." }
Cada CUI solo puede tener una cuenta. Si ya existe, devuelve 409.
